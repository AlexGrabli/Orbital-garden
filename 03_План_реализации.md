# Ночной Рой — План реализации по фазам

> План для ИИ-агента (Claude Code / Cursor / Codex) с установленным набором
> скиллов `awesome-gamedev-agent-skills` (роутер сам подгружает нужные SKILL.md).
> Принцип: **одна система = один промпт = один коммит = один headless-прогон**.
> Каждая фаза заканчивается запускаемым билдом.

Контекстные документы (лежат в корне репозитория, читаются агентом в каждой
сессии): `01_Core_Loop_и_правила_карт.md`, `02_Ростер_карточек.md`, этот файл.

---

## Фаза 0 — Инициализация (0.5–1 день)

**Цель:** проект, который собирается и пусто запускается на устройстве.

1. Создать проект Godot 4.x, структура:
   ```
   scenes/      ui/ game/ entities/
   scripts/     core/ systems/ data/
   assets/      sprites/ audio/ fonts/
   resources/   cards/ enemies/ waves/
   tests/       (headless GDScript-тесты)
   docs/        (этот GDD: файлы 01, 02, 03)
   ```
2. Project settings: базовое разрешение 640×360, stretch `canvas_items`,
   aspect `expand` (под любые экраны), ориентация — ландшафт.
3. `git init`, `.gitignore` для Godot, первый коммит.
4. Скопировать `01_*.md`–`03_*.md` в `docs/` и создать `AGENTS.md`
   со ссылками на них + правилом «одна система — один коммит».

**Контроль:** `godot --headless --quit` завершается без ошибок; пустая сцена
ставится на телефон через Android export preset.

## Фаза 1 — Играбельный скелет (1–2 недели)

**Цель:** полный забег от меню до поражения/победы на прямоугольниках
и эмодзи-плейсхолдерах. Графики нет — только системы.

Порядок задач (каждая — отдельный промпт агенту):

1. **Day/Night state machine** — `MainMenu → Day → Sunset → Night → Dawn →
   (Run end)`. Сердце игры, делается первой.
   *(скиллы: godot-nodes-scenes, godot-signals-groups)*
2. **Абстракция ввода.** Action map: `place_card`, `move_cursor`, `confirm`,
   `cancel`, `active_ability`. Биндинги: тач (тап/драг), геймпад (курсор),
   мышь+клавиатура. Прямые вызовы `Input.*` в геймплейном коде запрещены.
   *(input-systems)*
3. **Сетка станции 4×4.** Размещение/перемещение/удаление карт; «неудобные»
   клетки (камень, грязь) для Свинтуса; визуал соседства для синергий.
   *(godot-tilemap, godot-ui-control)*
4. **Колода и рука.** Колода → рука 3 карты → розыгрыш на сетку → драфт
   награды 1 из 3. Все 6 карт стартовой колоды как `.tres` по схеме CardResource.
   *(card-game, godot-resources)*
5. **Ресурсы и экономика дня.** Энергия/вода/биомасса, сбор в «утро»,
   трата днём, «ставка заката».
   *(godot-resources, godot-signals-groups)*
6. **Wave manager.** Волна читает сценарий из данных (направление, состав,
   тайминги спавна) — JSON/`.tres` в `resources/waves/`.
   *(roguelike, procedural-gen — позже; сначала 3 рукописные волны)*
7. **Auto-battle минимум.** Враги идут по путям к Ядру; турели стреляют
   по приоритету «ближайший к Ядру»; Ядро имеет HP; конец ночи по таймеру
   или зачистке.
   *(game-ai, godot-physics)*
8. **HUD.** Ресурсы, рука, прогноз атаки, HP Ядра, кнопка паузы.
   Anchors + safe area (чёлки/камеры телефонов). *(godot-ui-control, game-ui-ux)*
9. **Сохранение.** `user://save.json`, поле `save_version` С ПЕРВОГО ДНЯ;
   сохранение состояния забега на каждом «рассвете». *(save-systems)*
10. **Headless-скелет-тест.** Проект стартует, главная сцена грузится,
    симулируется 1 день без ввода. *(godot-gdscript-headless-testing)*

**Контроль:** APK на телефоне; забег 5 дней проходится «уродливо, но живо»;
тап и геймпад работают равнозначно.

## Фаза 2 — Глубина систем (2–4 недели)

**Цель:** игра, в которую интересно играть, всё ещё без финального арта.

1. Полный ростер 20 карт из `02_Ростер_карточек.md` (данные + эффекты).
2. Система синергий по тегам: «Ферма», «Электросеть», «Смрадный заслон»;
   таблица синергий — данные, не код.
3. 8 типов ксеноморфов Роя (архетипы: бегун, танк, роющий, летающий,
   плюющий, толкач, роевой мелкий, мини-босс). Каждый «спрашивает» с игрока
   конкретный ответ из ростера. *(ai-behavior-trees-utility-ai — только для
   элиты; рядовым хватит FSM)*
4. Генератор волн: из рукописных сценариев → параметрическая генерация
   с кривой сложности по дням. *(procedural-gen)*
5. Метапрогрессия: биомасса → разблокировки карт и стартовых бонусов,
   экран между забегами.
6. Ремонтный док: разрушенные карты возвращаются через 1 день за энергию.
7. **Баланс-стенд:** headless-симуляция 100 забегов ботом; метрика —
   винрейт 55–65% на дне 10; отчёт по картам-аутлайерам.
   *(godot-gdscript-headless-testing, performance-optimization)*

**Контроль:** 100 симуляций в CI зелёные; баланс-отчёт приложен к коммиту.

## Фаза 3 — Ассеты и game feel (2–3 недели)

1. **Арт-дирекшн через `create-game-assets`:** палитра дня (пастель) и ночи
   (тёмно-фиолетовый + биолюминесценция) зафиксированы в документе;
   размер тайла 32×32; один стиль-референс.
2. Генерация семействами: клетки сетки → классика (мех) → коровы → свиньи →
   растения → зверинец → Рой → UI-иконки. Каждое семейство нормализуется
   и проверяется в сцене.
3. День/ночь — шейдерный пресет поверх одних ассетов (не рисовать дважды).
   *(godot-shaders)*
4. **Game feel** *(game-feel, godot-animation)*: hit-stop при прорыве,
   лёгкий screen shake от взрыва Бурёнки, squash & stretch у цыплят,
   всплывающие числа урона, «сочные» награды рассвета.
5. **Аудио** *(audio-design, godot-audio)*: SFX (генерируются ИИ по описаниям),
   2-слойная адаптивная музыка (спокойный день / тревожная ночь), ducking
   музыки под взрывы.

**Контроль:** игра выглядит цельно на скриншоте; ни один ассет не выбивается
из палитры (проверка скриптом по таблице цветов).

## Фаза 4 — Мобильная адаптация и экспорт (1–2 недели)

1. Touch-UX: зоны тапа ≥48dp, драг карт с магнитом к клеткам, долгий тап =
   подсказка по карте, haptic на размещение/взрыв.
2. Safe areas + адаптив HUD под 16:9 / 18:9 / 20:9; ландшафт-онли
   (решение зафиксировано, портрет не поддерживаем).
3. Производительность *(performance-optimization)*: object pooling врагов,
   снарядов, частиц; бюджет — 60 fps на устройстве 2020 года; draw calls
   < 100 в ночной пик.
4. Экспорт *(godot-export)*: Android (APK + AAB, keystore), Linux X11
   (Steam Deck, проверить геймпад-навигацию по меню), Windows (Proton).
   iOS — Xcode-проект; финальная сборка требует Mac (единственный
   ручной этап, откладывается до soft launch).
5. Публикация *(itch-publish + butler)*: страница itch.io, closed build.

**Контроль:** 60 fps на среднем Android в пиковую волну; Deck: весь UI
проходится геймпадом без мыши.

## Фаза 5 — Цикл итераций (постоянный)

```
1. Фича/правка формулируется на человеческом языке (1 система!)
2. Если меняется дизайн — сначала обновить docs/01–03
3. Агент пишет код + headless-тест
4. 5 минут игры на устройстве → список правок
5. Коммит → повтор
```

## Операционные правила (не нарушать)

- **Новая сессия агента на каждую фазу** (контекстное окно — враг);
  `AGENTS.md` + docs/ дают полный контекст с нуля.
- **Тесты обязательны** на генератор волн и боевую математику.
- **`save_version` мигрируется**, сейвы игроков не ломаются никогда.
- **Тач и геймпад зеркалятся с первого дня** — «допилить потом» запрещено.
- **Числа баланса — в данных** (`resources/`), не в коде.
- Новые карты — только по правилам расширения из `02_Ростер_карточек.md`,
  раздел 8.
