# Ночной Рой — Core Loop и правила карточек

> Рабочее название: **«Ночной Рой» / Nightswarm** (варианты: «Огород на орбите», «Рассвет-9»)
> Жанр: roguelite deck-building + tower defense + cozy farm
> Движок: Godot 4.x (GDScript, текстовые сцены `.tscn` / ресурсы `.tres`)
> Платформы: Android, iOS, Steam Deck (Linux), портативные консоли

---

## 1. Сеттинг

Cozy sci-fi. Игрок — смотритель терраформинговой станции на краю колонизируемой
планеты. Днём — яркая пастельная «весёлая ферма»: генномодифицированные культуры,
киборг-скот, дроны. Ночью — тёмно-фиолетовая биолюминесцентная угроза: местная
ксенофауна («Рой») приходит на запах биомассы.

Тон: юмор, а не хоррор. Ксеноморфы — зубастые, но мультяшные «вредители огорода».

Фирменный визуальный приём: **одна и та же сцена в двух палитрах** — день/ночь,
реализуется шейдерным пресетом, а не двойным набором ассетов.

## 2. Дизайн-пиллары

1. **Всё, что выращено днём — сражается ночью.** Ферма и оборона — одна система,
   а не две параллельные.
2. **Решения важнее кликов.** Бой — auto-battle; игрок выигрывает днём,
   расставляя карты, а ночью наблюдает последствия (+1–2 активные способности).
3. **Маленькая сетка, глубокая тактика.** Сетка 4×4–5×5, соседские синергии,
   читаемость за 2 секунды. Подходит для игры одной рукой.
4. **Сессия 5–10 минут.** Один «день» = один естественный чекпоинт.

## 3. Core Loop (один день = 5–8 минут)

```
УТРО (≈30 сек)
  Сбор урожая → ресурсы (энергия/вода/биомасса)
  Добор руки до 3 карт (лимит руки — 5)

ДЕНЬ (2–3 мин)
  Разыграть 1–2 карты на сетку: посадить / построить / улучшить
  Переставить оборону под прогноз атаки
  (игра честно показывает: «Рой придёт с востока», если построен радар)

ЗАКАТ (≈10 сек)
  Ставка дня: потратить остаток воды на РОСТ или на БОЕПРИПАСЫ?
  РОСТ: каждая вода → +X HP ремонта всем размещённым картам.
  БОЕПРИПАСЫ: каждая вода → +Y зарядов картам с damage-эффектом.
  (X, Y — числа баланса в данных, не в коде)

НОЧЬ (2–3 мин)
  Волна. Auto-battle: юниты сражаются сами.
  У игрока 1–2 активные способности (тап = «орбитальный удар»)

РАССВЕТ
  Подсчёт потерь → награда: драфт 1 из 3 карт в колоду
  → следующий день сложнее (кривая волн)
```

## 4. Структура забега (run)

- Забег = **10–14 дней**, финал — **«Ночь Большого Роя»** (босс-волна).
- Поражение = разрушение Ядра станции.
- Метапрогрессия между забегами: биомасса тратится на разблокировку новых
  карт, стартовых бонусов и слотов колоды.
- Стартовая колода: 6 карт (фиксированный набор новичка, см. ростер).

## 5. Ресурсы (ровно три — жёсткое правило скоупа)

| Ресурс | Фаза | Источник | Трата |
|---|---|---|---|
| **Энергия** | обе | солнечные панели, Бурёнка-3000 | питание турелей/щитов ночью, постройка мех-карт |
| **Вода** | день | конденсаторы влаги | посадка/перемещение карт днём |
| **Биомасса** | мета | переработка урожая, награды | улучшения и разблокировки между забегами |

Запрещено добавлять новые ресурсы без явного решения гейм-дизайнера.
Любая карта работает максимум с 2 ресурсами.

Локальные запасы сущностей (заряды турели, запас кактуса, яйца курицы,
«молоко» коровы) — **не ресурсы** в смысле этого раздела, а per-entity
состояние размещённой карты. Глобальными ресурсами остаются ровно три.

## 6. Пять правил карточки (контракт для ИИ-агента)

1. **Двойное назначение обязательно.** У карты есть дневная и ночная функции,
   и дневная *подпитывает* ночную (эталон: Кактус-Батарея — копит энергию днём,
   стреляет пропорционально запасу ночью). Дневная функция может быть
   пассивным свойством из закрытого списка `day_property` (`free_move` —
   бесплатное перемещение), а не эффектом. Исключение — осознанный риск-дизайн
   (Свинья-Копилка), таких карт не больше 1–2 на весь пул.
2. **Читается за 2 секунды.** Одна иконка + одна строка механики на фазу.
   Составные условия («если X, то Y, но при Z…») допустимы только у редких карт.
3. **Максимум 2 ресурса** на карту (стоимость + эффект).
4. **Теги вместо хардкода синергий.** Синергии считаются по тегам
   (`био`, `мех`, `растение`, `животное`, `энергия`, `контроль`…).
   Новая карта = новый `.tres`-файл, код не трогаем.
5. **Классика якорит, био удивляет.** Целевое соотношение пула:
   ~40% понятных мех-построек (турель, стена, щит) и ~60% биоинженерии.

## 7. Закрытый список типов эффектов

Все эффекты карт реализуются комбинацией существующих типов —
новый код под новую карту НЕ пишется:

```
generate   — производство ресурса
heal       — лечение/ремонт союзника
damage     — урон (single / aoe / dot)
slow       — замедление
stun       — удержание цели
shield     — временный щит/абсорбция
taunt      — перенаправление агрессии врагов
spawn      — порождение юнита/мины/ловушки
reveal     — подсветка/разведка (бафф точности союзников)
buff       — усиление союзника по радиусу/тегу
convert    — конвертация ресурса/карты
summon_active — активная способность игрока (тап)
```

Каждый эффект параметризуется: `value`, `radius`, `duration`, `cooldown`,
`conditions` (теги соседей, запас ресурса и т.п.).

## 8. Редкость

- **common** — одна простая функция на фазу, без условий.
- **rare** — одна функция + условие (соседство, ресурсный порог).
- **epic** — составное поведение, риск-механики («бешеная корова»).

Стартовая колода — только common. Драфт после ночи: 3 карты
(взвешено по редкости), выбрать 1.

## 9. Синергии (стартовый набор)

Синергия активна при соседстве по сетке (4 направления, если не указано иное).

| Синергия | Условие | Эффект |
|---|---|---|
| **Ферма** | `животное` рядом с `растение` | оба +20% к дневному выходу ресурсов |
| **Электросеть** | непрерывная цепь `мех` + `энергия` | турели в сети не тратят заряд на первый выстрел ночи |
| **Смрадный заслон** | Свинья-Утилизатор + Тёлка-Притяжение | штраф точности врагов в поле замедления складывается ×2 |

Новые синергии добавляются данными (таблица условий по тегам), не кодом.

## 10. Проигрыш/победа и анти-фрустрация

- Ядро станции имеет HP; ночной прорыв снимает HP Ядра.
- Ночь НЕ обнуляет станцию: разрушенные карты уходят в «ремонтный док»
  и возвращаются через 1 день за энергию — cozy-игра не наказывает смертью контента.
- Прогноз атаки (радар) и «ставка заката» дают игроку ощущение контроля:
  поражение = моя ошибка планирования, а не случайность.
