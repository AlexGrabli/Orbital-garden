# Ночной Рой — Ростер карточек (вертикальный срез, 20 карт)

> Документ — источник данных для ИИ-агента. Каждая карта реализуется как
> Godot Resource (`.tres`) по схеме из раздела 1. Эффекты — ТОЛЬКО из
> закрытого списка типов (см. `01_Core_Loop_и_правила_карт.md`, раздел 7).
> Числа (стоимость, HP, урон) — стартовые, балансятся headless-симуляциями.

---

## 1. Схема данных карты (CardResource)

```gdscript
class_name CardResource extends Resource

@export var id: StringName
@export var name: String
@export var flavor_text: String
@export var art_day: Texture2D        # спрайт дня
@export var art_night: Texture2D      # спрайт ночи (или тот же + шейдер-пресет)
@export var cost_water: int = 0
@export var cost_energy: int = 0
@export var hp: int
@export var rarity: Rarity            # common | rare | epic
@export var tags: Array[StringName]   # bio, mech, plant, animal, energy,
                                      # control, economy, defense, wall...
@export var day_property: StringName = &"none"  # закрытый список: none | free_move
                                                # (пассивное дневное свойство вместо эффекта)
@export var day_effect: EffectData    # { type, value, radius, cooldown, conditions }
@export var night_effect: EffectData
```

Контракт фаз: дневная функция = `day_effect` **или** `day_property != &"none"`
(проверяется машинно в тесте контракта). Ночная функция обязательна —
исключение только осознанный риск-дизайн (Свинья-Копилка).

Правила заполнения: см. «Пять правил карточки» в документе 01.

Легенда стоимости: В = вода (дневная постройка), Э = энергия.

## 2. Классические постройки (мех) — 8 карт

### 2.1 Лазерная турель `turret_laser`
- Теги: `мех`, `энергия`, `оборона` · common · В1 Э2 · HP 30
- ☀️ Заряжается от сети: копит до 20 выстрелов (convert: энергия→заряд)
- 🌙 damage (single): 5 урона / 1 сек, радиус 3
- Заметка: базовая карта обороны, эталон читаемости. Входит в стартовую колоду.

### 2.2 Силовая стена `wall_barrier`
- Теги: `мех`, `стена` · common · В1 Э1 · HP 60
- ☀️ `day_property = free_move`: перемещение бесплатно (манёвр под прогноз атаки)
- 🌙 taunt (пассивная блокировка прохода)
- Входит в стартовую колоду.

### 2.3 Щитовой купол `shield_dome`
- Теги: `мех`, `энергия`, `оборона` · rare · В2 Э3 · HP 25
- ☀️ Копит заряд щита (до 40)
- 🌙 shield: абсорбирует урон по 2 соседним клеткам, пока заряд не исчерпан

### 2.4 Солнечная панель `solar_panel`
- Теги: `мех`, `энергия`, `экономика` · common · В1 · HP 20
- ☀️ generate: +4 энергии/день
- 🌙 convert: отдаёт запас турелям в радиусе 2 (1 энергия = 2 выстрела)
- Входит в стартовую колоду.

### 2.5 Конденсатор влаги `moisture_condenser`
- Теги: `мех`, `экономика` · common · Э1 · HP 20
- ☀️ generate: +3 воды/день
- 🌙 heal: 2 HP/5 сек растениям в радиусе 1; тушит поджоги
- Входит в стартовой колоде.

### 2.6 Радарная вышка `radar_tower`
- Теги: `мех`, `разведка` · common · В1 Э2 · HP 20
- ☀️ reveal: показывает прогноз ночной атаки (направление, состав волны)
- 🌙 buff: +25% точности союзникам в радиусе 3

### 2.7 Ремонтный дрон `repair_drone`
- Теги: `мех`, `поддержка` · rare · В1 Э2 · HP 15
- ☀️ heal: чинит 10 HP постройкам после ночи (приоритет — самые повреждённые)
- 🌙 shield: мгновенный щит 15 HP одному союзнику, cooldown 20 сек

### 2.8 Орбитальный удар `orbital_strike`
- Теги: `мех`, `активная` · rare · В0 Э4 · HP — (не размещается, слот способности)
- ☀️ Привязка к сектору поля (выбор зоны 2×2)
- 🌙 summon_active: тап игрока = залп 30 урона по зоне, 1 заряд за ночь
- Заметка: единственная «ручная» мощь ночи. Ключ к ощущению агентности.

## 4. Свиньи (утилиты / риск) — 3 карты

### 4.1 Свинья-Копилка `pig_bank`
- Теги: `био`, `животное`, `экономика` · rare · В1 · HP 25
- ☀️ convert: излишки энергии → золотые жёлуди (мета-валюта магазина)
- 🌙 НЕ действует (спит). Риск-дизайн: при разрушении игрок теряет
  дневной заработок жёлудей. На карте всегда видна пометка риска.
- Заметка: единственная карта без ночной функции — осознанное исключение
  из правила двойного назначения.

### 4.2 Свинья-Бур «Свинтус-Экскаватор» `pig_drill`
- Теги: `био`, `животное`, `утилита` · rare · В2 · HP 45
- ☀️ Открывает для застройки «неудобные» клетки рядом с собой (камень, грязь)
- 🌙 spawn: подземные шипы-ловушки на 2 клетках путей врагов,
  damage 8 + slow при срабатывании
- Контрпика роющих врагов (см. ростер Роя).
- Внешность: свинья с кибернетическими ногами-бурами.

### 4.3 Свинья-Утилизатор `pig_recycler`
- Теги: `био`, `животное`, `контроль`, `экономика` · rare · В1 · HP 35
- ☀️ convert: съедает ненужные карты из руки (1/день) → +2 биомассы
- 🌙 debuff-аура: враги в радиусе 2 получают -30% точности (облако вони)
- Синергия: «Смрадный заслон».
- Убрано из черновика: случайное поедание яиц Бомбо-курицы (скрытый негатив).
  Вместо этого — явное предупреждение «опасное соседство» при размещении.

## 8. Правила расширения ростера (для агента)

1. Новая карта = новый `.tres` + запись в реестре. Код не меняется.
2. Эффекты — только из закрытого списка типов. Нужен новый тип эффекта —
   это отдельная задача с тестами, а не часть карты.
3. Проверка контракта перед коммитом: есть ли обе фазы? ≤2 ресурсов?
   читается ли строка механики за 2 секунды? теги заполнены?
4. Каждая новая карта проходит 100 headless-симуляций ночи:
   винрейт забега с картой должен остаться в коридоре 55–65%.
5. Пул роста: 20 (срез) → 35 (soft launch) → 50 (релиз). Редкости новых
   карт: не чаще 1 epic на 5 добавленных.
