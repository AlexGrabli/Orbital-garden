# Orbital Garden — Фаза 0: чек-лист первой сессии Kimi Code

Проект: `B:\\GameProject\\orbital-garden` · Godot 4.x · одна сессия «разработчик».

\---

## Шаг 0. Подготовка (вручную, без агента)

1. Положить в корень проекта: `AGENTS.md`.
2. Первую строку AGENTS.md заменить на:
`# AGENTS.md — «Orbital Garden» (рабочее название «Ночной Рой» / Nightswarm)`
3. Три md-файла (`01\_...`, `02\_...`, `03\_...`) переместить в подпапку `docs\\`
(AGENTS.md ссылается на `docs/01–03`).
4. Открыть терминал в папке проекта:

```powershell
   cd B:\\GameProject\\orbital-garden
   kimi
   ```

   (если `godot` не в PATH — агенту пригодится полный путь к exe, например
`C:\\Program Files\\Godot\\Godot\_v4.x\_win64.exe`)

\---

## Шаг 1. Структура и настройки проекта

Промпт агенту:

```
Выполни шаги 1–2 Фазы 0 из docs/03\_План\_реализации.md и правил AGENTS.md:

1. Создай структуру папок:
   scenes/ui, scenes/game, scenes/entities,
   scripts/core, scripts/systems, scripts/data,
   assets/sprites, assets/audio, assets/fonts,
   resources/cards, resources/enemies, resources/waves,
   tests, docs
2. Настрой проект: базовое разрешение 640×360,
   stretch mode canvas\_items, aspect expand, ориентация ландшафт.
   Главная сцена: пустая сцена Main (scenes/game/main.tscn) с фоном.

Ничего больше не делай. Контроль: запусти godot --headless --quit —
должно завершиться без ошибок.
```

**Проверка вручную:** `godot --headless --quit` в терминале → код 0, нет ERR в выводе.

## Шаг 3. Headless-дымовой тест

Промпт:

```
Создай tests/smoke\_test.gd: скрипт запускается headless, загружает
главную сцену, ждёт 3 кадра, проверяет, что дерево сцен не пустое,
печатает SMOKE\_OK и завершает процесс кодом 0. Любая ошибка — код 1.
Запусти: godot --headless -s res://tests/smoke\_test.gd
```

**Проверка:** в выводе есть `SMOKE\_OK`. Это база, на которую дальше
навешиваются тесты боёв, волн и экономики (Фазы 1–2).

## Что дальше (не в этой сессии)

Следующая сессия — **задача 1 Фазы 1: Day/Night state machine**
(`MainMenu → Day → Sunset → Night → Dawn`), это сердце игры.
Перед ней запустите архитектора в Plan mode:

```

```

## Операционные правила напоминания

* Агент свернул не туда → `Ctrl-C` / новая сессия, план читает AGENTS.md+docs.
* Каждый шаг заканчивайте зелёным headless-прогоном и коммитом.
* Агент предлагает новый ресурс/тип эффекта → стоп, это решение дизайнера (docs/01).
